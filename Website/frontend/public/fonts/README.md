# Open Sans

Vendored from `@fontsource-variable/open-sans@5.3.0` (Google Fonts).

Licensed under the SIL Open Font License 1.1; see OFL.txt.
Includes normal and italic faces at weights 300 through 800.
The website uses subsetted variable WOFF2 files with unicode ranges, and Expo uses static TTF files for reliable native weight selection.

See `scripts/bundle-open-sans.py` for regeneration instructions. No external font service is used during builds or at runtime.
